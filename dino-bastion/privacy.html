Privacy Policy

Draft · November 12, 2026

Local game data

The game saves progress, settings, virtual credits and reward-claim records on your device. Clearing the game’s stored data removes that local progress.

TikTok sign-in

When enabled, the game sends a temporary TikTok authorization code to the game’s server. The server exchanges it with TikTok and stores an app-specific user identifier and session records for sign-in. It discards the TikTok access and refresh tokens. The service uses connection information in memory to limit abuse.

Ads and revisit rewards

When enabled, TikTok provides advertising, home screen shortcuts and profile revisit features. The game uses completion and eligibility signals to grant rewards. TikTok’s handling of platform data is described in its own privacy policy.

Website

This site serves information and policy pages. It includes no game login, tracking script or contact form. The hosting provider may process connection information to deliver and secure the pages.

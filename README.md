# CHARGE TRADE LLC

Responsive company website built as a single HTML file. Open `index.html` directly, or serve this directory with any static web host.

- Company contact: wenziheng666@outlook.com
- Includes standalone `privacy.html` and `terms.html` pages, linked from the homepage.
- No build step or JavaScript dependencies. Google Fonts is optional; local fonts are used as fallback.

Before using the general policy for an actual game, supply and verify that game's data practices, SDK providers, retention periods, audience, and jurisdiction-specific disclosures. This website does not configure any game SDKs.

## GitHub Pages
In repository Settings → Pages, select Deploy from a branch, then `main` and `/ (root)`.
